# Panorama Cloud 0.4.8.2.8 — Selección sutil de tarjeta

Base: Panorama Cloud 0.4.8.2.7.

## Cambio visual
- La tarjeta seleccionada conserva un fondo apenas diferenciado.
- Se agrega un borde fino de 1 px usando el color de acento del tema suavizado.
- Se elimina cualquier brillo, halo o sombra especial de selección.
- El objetivo es que la selección sea clara tanto en modo claro como oscuro sin competir con el resto de la interfaz.

No se modificó lógica financiera, navegación, Supabase ni APIs.
