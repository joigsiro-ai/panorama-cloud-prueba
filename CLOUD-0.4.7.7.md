# Panorama Cloud 0.4.7.7 — Recurrentes: formulario por destino

- El alta/edición de recurrentes muestra **Cuenta** solo para Efectivo / Débito / Transferencia.
- Para **Débito automático en tarjeta**, oculta Cuenta y muestra únicamente **Tarjeta**.
- El importe informa automáticamente la moneda de la cuenta o tarjeta seleccionada.
- Los selectores de tarjeta incluyen la moneda para evitar ambigüedades.
- Se conserva la lógica de destino y día introducida en 0.4.7.6.
